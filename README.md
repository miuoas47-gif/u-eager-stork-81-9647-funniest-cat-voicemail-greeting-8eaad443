A tiny Python program that prints the funniest voicemail greeting a cat would ever record: Whiskers can't come to the phone because he's sitting on it, and any message you leave after the beep is getting knocked off the table. Run it and you get exactly one line, every time — deterministic, no arguments, no network, just one very unbothered cat.

## Run it

```sh
python3 main.py
```
